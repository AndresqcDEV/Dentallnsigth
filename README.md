# Dentallnsigth
DentalInsight – CRM para Clínicas Odontológicas


## Sobre o Projeto

O **DentalInsight** é um sistema CRM (Customer Relationship Management) desenvolvido para auxiliar na gestão de clínicas odontológicas, centralizando informações de pacientes, consultas, procedimentos e pagamentos em uma única plataforma.

O projeto foi desenvolvido como parte da disciplina de **Projeto Integrador** do curso de **Análise e Desenvolvimento de Sistemas do Centro Universitário de Brasília (CEUB)**.

---

## Objetivo

O objetivo do sistema é modernizar e otimizar os processos administrativos e clínicos da clínica odontológica, reduzindo controles manuais e melhorando a organização das informações.

---

## Funcionalidades

### Pacientes
- Cadastro de pacientes;
- Atualização de dados cadastrais;
- Consulta ao histórico do paciente.

### Consultas
- Agendamento de consultas;
- Reagendamento;
- Controle de horários.

### Atendimentos
- Registro de consultas realizadas;
- Histórico clínico.

### Procedimentos
- Registro de procedimentos odontológicos;
- Controle de valores e observações.

### Financeiro
- Registro de pagamentos;
- Controle financeiro da clínica;
- Relatórios financeiros.

### Arquivos
- Upload de exames;
- Upload de documentos;
- Armazenamento de arquivos clínicos.

### Relatórios
- Pacientes atendidos;
- Consultas realizadas;
- Relatórios financeiros.
